## 1. 프로젝트 소개

**여기남김**은 실제 장소와 사용자의 기록을 연결하는 위치 기반 기록 서비스입니다.

사용자는 카카오맵 기반으로 주변 장소를 탐색하고, 특정 장소의 보드에 포스트잇, 이미지, 텍스트 형태의 흔적을 남길 수 있고
남겨진 흔적은 같은 장소를 방문한 다른 사용자들과 공유되며, 사용자는 추천, 신고, 보관함 기능을 통해 기록을 관리할 수 있습니다.

또한 사용자가 직접 커스텀 보드를 생성하고 초대 링크를 통해 다른 사용자를 참여시킬 수 있어, 장소 기반 기록뿐만 아니라 
여행, 모임, 행사와 같은 그룹 단위의 기록도 함께 관리할 수 있습니다.

## 1.1 프로젝트 이름

**여기남김**

“여기남김”은 사용자가 특정 장소나 보드에 자신의 기억과 경험을 남긴다는 의미를 담고 있습니다.
이 프로젝트명은 사용자가 방문한 공간에서의 순간과 감정을 기록하고, 다른 사용자들과 함께 공유하는 서비스의 방향성을 표현합니다.

### 1.2 기획 의도 및 배경

--1--
기존 리뷰 서비스는 장소를 별점이나 후기 중심으로 평가하는 구조가 많아, 사용자가 방문한 공간에서 느낀 감정이나 순간적인
경험을 자유롭게 남기기 어렵습니다. 또한 SNS는 개인 피드 중심으로 기록이 쌓이기 때문에 특정 장소에 대한 여러 사용자의
기록을 한곳에서 확인하기 어렵다는 한계가 있습니다.

이 프로젝트는 이러한 한계를 보완하기 위해, 기록의 중심을 개인 피드가 아닌 “장소”와 “보드”로 설정했습니다. 
사용자가 남긴 기록이 개인 공간에만 저장되는 것이 아니라, 특정 장소나 커스텀 보드 안에 함께 모이도록 하여 
여러 사용자의 경험을 하나의 공간에서 확인할 수 있도록 기획했습니다.

이를 통해 **여기남김**은 단순한 장소 평가나 개인 게시물 공유를 넘어, 공간과 추억을 중심으로 여러 사용자의 경험이 함께
쌓이는 기록 서비스를 목표로 합니다.


--2--
카페, 전시회, 여행지, 행사장처럼 사람들이 방문하는 공간은 단순히 정보를 확인하는 대상이 아니라, 개인의 감정과 경험이
쌓이는 장소입니다. 하지만 기존 리뷰 서비스는 별점이나 후기 중심으로 장소를 평가하는 구조가 많아, 사용자가 그 공간에서
느낀 감정이나 순간적인 경험을 자유롭게 남기기 어렵습니다.

또한 SNS는 개인 피드 중심으로 기록이 쌓이기 때문에 특정 장소에 대한 여러 사용자의 기록을 한곳에서 확인하기 어렵고
시간이 지나면 기록이 흩어지는 한계가 있습니다.

이 프로젝트는 이러한 문제를 보완하기 위해, 기록의 중심을 개인 피드가 아닌 “장소”와 “보드”로 설정했습니다. 
사용자가 남긴 기록이 특정 장소나 커스텀 보드 안에 함께 모이도록 하여, 
여러 사용자의 경험을 하나의 공간에서 확인할 수 있는 서비스를 기획했습니다.

이를 통해 **여기남김**은 단순한 장소 평가나 개인 게시물 공유를 넘어, 공간과 추억을 중심으로 여러 사용자의 경험이 함께
쌓이는 기록 서비스를 목표로 합니다.
